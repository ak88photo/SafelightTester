# SafelightTester — тестер безопасного света для Ч/Б печати

Arduino Uno + спектральный сенсор AS7343 (I2C). Проверяет, что свет в тёмной
комнате не засветит чёрно-белую фотобумагу.

## Критерий

Свет безопасен, если в нём **нет синего и зелёного**, а красный пик **не
сдвинут в оранжевый**. Все «опасные» каналы сравниваются с красным F6
(640 нм), а не в абсолютных отсчётах: фильтры AS7343 немного пропускают
красный во все каналы, и эта утечка растёт вместе с яркостью.

| Каналы | Что проверяется | Превышение |
|---|---|---|
| F1 405, F2 425, FZ 450, F3 475, F4 515, F5 550 (узкие) | доля от F6 не выше утечки фильтров ×2 | **ОПАСНО** — реальный синий/зелёный |
| FY 555 (широкий) | FY/F6 ≤ 0,8 | **ПОГРАНИЧНО** — жёлто-оранжевая часть |
| FXL 600 (широкий) | FXL/F6 ≤ 1,1 / ≤ 2,0 | **ПОГРАНИЧНО** (пик ~605–620 нм) / **ОПАСНО** (оранжевый) |
| F6 640, F7 690, F8 745, NIR 855 | — | в вердикте не участвуют |

Для всех каналов есть ещё абсолютный пол шума — он ловит свет вообще без
красного (например, синий светодиод).

Пороги откалиброваны 02.10.2026 по красному кристаллу Cree XM-L RGBW
(~620–630 нм): FY/F6 = 0,40, FXL/F6 = 0,87, узкие каналы — 0,3–1,4 % от F6.
Калибровка по одному светодиоду: у глубокого красного (660 нм) утечка в
синие каналы может быть другой — при ложном «ОПАСНО» на нём пороги
`LEAK_LIMIT` надо перепроверить.

## Подключение

```
AS7343     Arduino Uno
VIN   ->   5V
GND   ->   GND
SDA   ->   A4
SCL   ->   A5
```

LCD 16×2: RS=D6, EN=D7, DB4…DB7=D8…D11. Кнопка — между D2 и GND
(внутренняя подтяжка).

Сенсорный модуль ставьте **окном вверх, на уровне бумаги** на рабочем столе —
он измеряет то, что «видит» бумага.

## Прошивка

```bash
arduino-cli compile --fqbn arduino:avr:uno ./SafelightTester
arduino-cli upload --fqbn arduino:avr:uno -p /dev/cu.usbmodemXXXX ./SafelightTester
arduino-cli monitor -p /dev/cu.usbmodemXXXX -c baudrate=115200
```

## Как пользоваться

1. В комнате **полностью выключить свет** (и фонарь, и окна) → нажать `d`
   (темновой уровень). Если замер подозрительно яркий — прошивка предупредит.
2. Включить тестируемый фонарь → нажать `s` (одиночный тест) или `l`
   (длинный: 5 замеров на максимальной чувствительности — ловит даже слабый
   сине-зелёный отсвет). `c` — непрерывный режим каждые ~4 с.

Порядок обязателен: без темнового уровня тест не запустится (строгость!).

С кнопкой: «Turn off all lights» → кнопка (снимается темновой уровень) →
«Turn on safelight» → кнопка (замер) → результат на экране.

### Вердикты

| Serial | LCD | Значение |
|---|---|---|
| **БЕЗОПАСНО** | `SAFE` | синего/зелёного нет, красный пик на месте |
| **ПОГРАНИЧНО** | `BORDER FXL 600` | пик сдвинут к оранжевому — для лита и долгой работы проверить бумагой |
| **ОПАСНО** | `UNSAFE! F5 550` | найден синий/зелёный/оранжевый свет, на экране — какой канал |
| **ПЕРЕСВЕТ** | `Too bright` | датчик пересвечен даже на минимальной экспозиции — отнести дальше |
| **СВЕТА НЕ ОБНАРУЖЕНО** | `No light` | сенсор накрыт или свет выключен |

Вторая строка LCD — `FXL/F6`: у честного красного ~620–630 нм около 0,9;
чем больше, тем ближе пик к оранжевому.

В таблице замера колонка `стат.`: `o` — канал в норме, `?` — пограничный,
`!` — опасный. `raw` — сырые отсчёты, `сигнал` — после вычитания темнового
уровня, `порог` — допустимый уровень для канала.

## Как настроить строгость

Пороги вердикта — в `SafelightTester/verdict.h`:

- `LEAK_LIMIT` — допустимая доля от F6 для узких каналов F1…F5;
- `FY_BORDER`, `FXL_BORDER`, `FXL_UNSAFE` — границы для широких FY и FXL;
- `VERDICT_ABS_FLOOR` — пол шума в отсчётах.

После правки порогов прогоните проверку на компьютере — она содержит
реальный замер красного XM-L и синтетические опасные случаи:

```bash
c++ -std=c++11 -Wall -I SafelightTester test/verdict_test.cpp -o /tmp/verdict_test && /tmp/verdict_test
```

## Ограничения и оговорки

- Сенсор оценивает **спектр**, а не дозу: «БЕЗОПАСНО» не говорит, сколько
  минут бумага может лежать под светом. Для лит-печати (10–20 мин в
  проявителе) это особенно важно.
- Сенсор оценивает спектр, а не светочувствительность конкретной бумаги.
  Финальный арбитр — бумажный тест: кусок бумаги с монетой, 30 мин под фонарём
  на рабочем расстоянии, проявить, сравнить с контрольным листом. Для лита —
  с предзасветкой как для настоящего отпечатка и на полное время проявления.
- NIR (855 нм) бумагу не засвечивает — в вердикте не участвует.
- Критерий рассчитан на ч/б бумагу; цветные и панхроматические материалы
  требуют почти полной темноты (красный свет опасен).
