# SafelightTester — тестер безопасного света для Ч/Б печати

Arduino Uno + спектральный сенсор AS7343 (I2C). Проверяет, что свет в тёмной
комнате не засветит чёрно-белую фотобумагу.

## Критерий (строгий)

Единственный критерий: свет безопасен, если его излучение **целиком ≥ 625 нм**.
Любая обнаружимая энергия ниже 625 нм — провал.

Сенсор измеряет 12 полос: F1 405, F2 425, FZ 450, F3 475, F4 515 (опасные,
абсолютный порог), F5 550, FY 555, FXL 600 (опасные, порог относительно
красного F6 — туда попадают хвосты фильтров от честного красного света),
F6 640, F7 690, F8 745, NIR 855 (безопасные).

## Подключение

```
AS7343     Arduino Uno
VIN   ->   5V
GND   ->   GND
SDA   ->   A4
SCL   ->   A5
(опция) зелёный светодиод D8 = PASS, красный D9 = FAIL
```

Сенсорный модуль ставьте **окном вверх, на уровне бумаги** на рабочем столе —
он измеряет то, что «видит» бумага.

## Прошивка

```bash
arduino-cli compile --fqbn arduino:avr:uno ./SafelightTester
arduino-cli upload --fqbn arduino:avr:uno -p /dev/cu.usbmodemXXXX ./SafelightTester
arduino-cli monitor -p /dev/cu.usbmodemXXXX -c baudrate=115200
```

## Как пользоваться

1. В комнате **полностью выключить свет** (и фонарь, и окна) → нажать `d`
   (темновой уровень). Если замер подозрительно яркий — прошивка предупредит.
2. Включить тестируемый фонарь → нажать `s` (одиночный тест) или `l`
   (длинный: 5 замеров на максимальной чувствительности — ловит даже слабый
   сине-зелёный отсвет). `c` — непрерывный режим каждые ~4 с.

Порядок обязателен: без темнового уровня тест не запустится (строгость!).

### Вердикты

| Вердикт | Значение |
|---|---|
| **БЕЗОПАСНО [строгий режим]** | свет целиком ≥ 625 нм, сине-зелёного ниже порога нет |
| **ОПАСНО** | обнаружен свет < 625 нм (в выводе — какой канал превышен) — такой свет засвечивает бумагу |
| **СВЕТА НЕ ОБНАРУЖЕНО** | сенсор накрыт или свет выключен |

В таблице замера колонка `стат.`: `o` — канал в норме, `!` — превышен порог.
`сигнал` — отсчёты после вычитания темнового уровня, `порог` — допустимый
уровень для этого канала.

## Как настроить строгость

Все пороги — константы в начале `SafelightTester.ino`:

- `ABS_FLOOR` — абсолютный пол шума (counts) для каналов 405–515 нм;
- `REL_F5_FY` — допустимый «хвост» красного в каналах 550/555 нм, доля от F6;
- `REL_FXL` — допустимый уровень FXL (600 нм) относительно F6 (640 нм):
  если FXL заметно выше F6 — свет центрирован ниже 625 нм, это провал.

Уменьшайте `REL_F5_FY`/`REL_FXL` и `ABS_FLOOR` — тест станет строже
(но появится риск ложных срабатываний на хвостах честного красного).

## Ограничения и оговорки

- Сенсор оценивает **спектр**, а не светочувствительность конкретной бумаги.
  Финальный арбитр — бумажный тест: кусок бумаги с монетой, 30 мин под фонарём
  на рабочем расстоянии, проявить, сравнить с контрольным листом.
- Каналы F5/FY/FXL имеют хвосты в красную область — поэтому для них порог
  относительный, а не нулевой.
- NIR (855 нм) бумагу не засвечивает — в вердикте не участвует.
- Критерий «≥ 625 нм» — для ч/б бумаги; цветные и панхроматические материалы
  требуют почти полной темноты (красный свет опасен).
